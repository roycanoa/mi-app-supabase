# Mi Proyecto con Supabase
Proyecto desarrollado para la materia de Programación Orientada a Objetos en FIME.

## Descripción
Una aplicación simple en Node.js que se conecta a una base de datos en la nube (Supabase) para gestionar registros de estudiantes.

## Tecnologías
* Node.js
* Supabase JS Client
* Git/GitHub

## Cómo ejecutarlo
1. Clonar el repositorio.
2. Ejecutar `npm install`.
3. Configurar las API Keys en `index.js`.
4. Correr con `node index.js`.
